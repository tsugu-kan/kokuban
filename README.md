# 今週の黒板

精肉店の店頭黒板に書く「曜日ごとのおすすめ」を組み立てる Web アプリです。
ブラウザで開くだけで動きます(インストール不要・HTML ファイル1つ)。

## できること

- 決まった催しを自動で入れる
  - 水曜: よりどり2P 1000円・ポイント5倍
  - 土日: 焼肉セット 3980円
  - 第2土日: びっくり市
  - 毎月28・29日: 29の日セール(最優先)
  - 1月1日: 定休日
- 月・火・木・金のおすすめを提案(豚2日・牛2日が基本、前週と同じ品は避けやすい)
- 季節のテーマで売り方を変える(冬は鍋・すき焼き向けの薄切り多め、夏は焼肉・冷しゃぶ)。自動切り替えか手動で選択
- 黒板は日曜の夕方に翌週分(月〜日)へ書き換える前提。開くと翌週分が出る
- 天気予報(気象庁の週間予報、範囲外は Open-Meteo、大阪)を反映。寒い日・雨の日は鍋向け、暑い日は焼肉向けを出しやすくする
- 「別の案」で1日だけ差し替え、「固定」で組み直しから守る
- 在庫が多い品を「優先」に入れると、黒板に必ず入る(棚卸は毎月10・20・30日)
- 品目と価格の台帳を編集・追加できる
- 黒板の文面をコピーして、LINE やメモに貼れる

## 使い方

`index.html` をブラウザで開くか、GitHub Pages で公開した URL にアクセスします。

## データの保存先

入力した内容は、開いたブラウザの中(localStorage)にだけ保存されます。
端末やブラウザが変わると共有されません。ブラウザの閲覧データを削除すると消えます。

## 技術

- HTML / CSS / JavaScript のみ(ライブラリなし)
- フォント: Google Fonts(Yomogi, Zen Kaku Gothic New, Zen Old Mincho)
